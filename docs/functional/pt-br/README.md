## Ações
<br/>

<img align="left" src="../img/move-action.png" alt="Ação de mover" />

**Mova** pokémons entre boxes e armazenamentos.

<br/>
<br/>
<br/>
<br/>
<br/>

<img align="right" src="../img/move-attached.png" alt="Mover anexado" />

**Mova como anexado**, criando uma cópia que sincroniza entre o armazenamento do PKVault e o save após qualquer alteração (subir de nível, mudança de movimentos, etc).

<br/>
<br/>
<br/>

<img align="left" src="../img/edit-action.png" alt="Ação de editar" />

**Edite** o apelido, movimentos e a distribuição de EVs dos pokémons.

<br/>
<br/>
<br/>
<br/>
<br/>
<br/>
<br/>
<br/>
<br/>
<br/>
<br/>

<img align="right" src="../img/evolve-action.png" alt="Ação de evoluir" />

**Evolua** pokémons que necessitam de troca.
<br/>
Pode ser necessário um item segurado.

<br/>
<br/>
<br/>
<br/>
<br/>
<br/>
<br/>

<img align="left" src="../img/multi-select.png" alt="Seleção múltipla" />

**Selecione** múltiplos pokémons antes de mover, editar, etc.

<br/>
<br/>
<br/>
<br/>
<br/>

<img align="right" src="../img/sort-action.png" alt="Ação de ordenar" />

**Ordene** pokémons em múltiplas boxes com base em uma Pokédex específica.

<br/>
<br/>
<br/>
<br/>
<br/>
<br/>
<br/>
<br/>
