# PKVault - Recursos

O PKVault é um aplicativo gratuito e de código aberto para gerenciamento centralizado de Pokémon, incluindo armazenamento, Pokédex, manipulação de Pokémon e arquivos de salvamento (*saves*).
Ele permite que você:

- importe arquivos de salvamento de Pokémon (Nintendo Switch, Game Boy, 3DS, etc.)
- organize Pokémon em bancos e caixas
- gerencie com segurança modificações nos arquivos de salvamento (sistema de sessão antes de salvar)
- consulte uma Pokédex completa com todos os Pokémon
- proteja dados com backups automáticos

Foi projetado para funcionar 100% offline, em modo de usuário único, e é compatível com todas as gerações, da primeira até a mais recente.

## Escopo e Limitações

O PKVault utiliza o PKHeX internamente para a manipulação de Pokémon e arquivos de salvamento, mas não tem como objetivo oferecer os mesmos recursos.

Além dos recursos principais, o aplicativo pode oferecer funcionalidades secundárias de conveniência: evolução por troca, alteração de golpes, etc. No entanto, o PKVault não oferecerá opções de edição que vão além do uso clássico e cotidiano.

O PKVault não incentiva o uso de trapaças (*cheats*), exceto por opções de conveniência.

O PKVault pode:

- ler arquivos de salvamento
- modificar e mover Pokémon
- criar variantes de Pokémon

O PKVault não pode:

- modificar atributos/IVs de Pokémon
- criar intencionalmente Pokémon ilegais
- modificar diretamente os jogos em si
