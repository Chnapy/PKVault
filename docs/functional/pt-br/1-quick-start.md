# 1 - Início rápido

Você pode começar a usar o PKVault rapidamente seguindo alguns passos:

- Nas configurações, informe um ou mais caminhos para seus arquivos de save
- Na página de armazenamento, selecione um dos seus saves
- O conteúdo do armazenamento do save será exibido
  - Selecione uma caixa do armazenamento
  - Selecione um dos Pokémon
  - Mova o Pokémon do save para o armazenamento do PKVault
  - Salve

Pronto! Agora você tem um bom ponto de partida para usar o PKVault.

Considere consultar o restante da documentação para obter mais informações sobre os recursos do aplicativo.
