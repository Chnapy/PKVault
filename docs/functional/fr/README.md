## Actions
<br/>

<img align="left" src="../img/move-action.png" alt="Move action" />

**Déplacez** les pokémons entre les boîtes et stockages.

<br/>
<br/>
<br/>
<br/>
<br/>

<img align="right" src="../img/move-attached.png" alt="Move attached" />

**Déplacez rattaché**, créant une copie synchronisée entre le stockage PKVault et la sauvegarde après le moindre changement (level up, changement de capacité, etc)

<br/>
<br/>
<br/>

<img align="left" src="../img/edit-action.png" alt="Edit action" />

**Editez** les pokemons: surnom, capacités et balance des EVs.

<br/>
<br/>
<br/>
<br/>
<br/>
<br/>
<br/>
<br/>
<br/>
<br/>
<br/>

<img align="right" src="../img/evolve-action.png" alt="Evolve action" />

**Evoluez** les pokémons qui requierent un échange.
<br/>
Le port d'un objet peut être requis.

<br/>
<br/>
<br/>
<br/>
<br/>
<br/>
<br/>

<img align="left" src="../img/multi-select.png" alt="Multi-select" />

**Sélectionnez** plusieurs pokémons avant de déplacer, éditer, etc.

<br/>
<br/>
<br/>
<br/>
<br/>

<img align="right" src="../img/sort-action.png" alt="Sort action" />

**Triez** les pokémons sur plusieurs boîtes en suivant un Pokédex donné.

<br/>
<br/>
<br/>
<br/>
<br/>
<br/>
<br/>
<br/>
